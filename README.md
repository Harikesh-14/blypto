# Blypto

A dedicated platform to manage and guide a DSA learning journey. The goal of the website is to focus on curation, cognitive progression, and habit building.

## Features

1. Topic-wise question bank (structured sheets).
2. Progress-based question recommendation.
3. Answers and explanations hub.
4. Streak tracker and habit engine.

## Future Features

1. Interactive visual roadmap view.
2. Spaced repetition revision box (Leitner/SM-2 system).
